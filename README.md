# The Saturday Globe — 21 November 2026

A single 1024×1024 newspaper front page summing up the world's news of
Saturday, 21 November 2026: Iran's missile and drone strikes on US positions
in Bahrain, Mexico's capture of "El Chapo Isidro", the double-tap strike on
Kryvyi Rih, Russian missiles landing in Poland, COP31 in overtime, markets
in correction, Trump telling Europe to defund Ukraine, a magnitude 6.7 quake
in Peru, and a dengue breakthrough in Belo Horizonte. Every fact was checked
against at least two sources (Reuters, Associated Press, Xinhua, IRNA, US
Geological Survey).

The page is a self-contained HTML file (`news.html`, system fonts only, no
external resources, no photos) rendered in headless Chromium to `entry.png`.
`main.ts` copies the bundled `entry.png` to the output directory.
